## 📌 Features & Architecture
- **Interactive SOC Lab Showcase:** In-depth documentation and architecture breakdowns of threat detection, Sysmon telemetry, and automated Active Response environments.

- **Responsive Cybersecurity UI:** Modern cyber-dark themed layout engineered with lightweight, semantic HTML5, CSS3, and JavaScript.
- **Zero-Dependency Performance:** Optimized for instantaneous load latency and continuous deployment via GitHub Pages.
